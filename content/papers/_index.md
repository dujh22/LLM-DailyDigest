# 论文

> 大模型**论文精选与追踪**：每日从 arXiv / HF Daily Papers / 大厂 Blog 中筛出值得精读的工作。

本栏目按方向归档论文速读与精读笔记，附 arXiv 链接、代码与数据集（如有）。
点击下方列表浏览已收录条目，或前往「[资源 ‧ 论文](/resources/papers/)」查看通用检索渠道。

## 阅读约定

- **速读**：一句话动机 + 核心方法 + 关键结果，便于快速判断是否深挖。
- **精读**：问题定义、方法细节、实验设置、消融与局限，附复现要点。
- **关联**：每篇论文尽可能标注所属「[主题](/topic/)」与「[研究](/research/)」方向，便于交叉检索。

> 论文链接统一指向 arXiv abs 页；若有官方代码 / 数据集，会在条目内一并标注。
